# Diwas Neupane Portfolio

This is my personal portfolio website showcasing projects, skills, and contact information. It's a single-file, responsive site built using **Tailwind CSS** and **vanilla JavaScript**.

---

## Features
- Responsive navigation bar (desktop + mobile)
- Hero section with brief introduction
- About section
- Projects showcase
- Skills & tools section
- Contact form (replace with a real backend for production)
- Footer with current year

## How to Run Locally
1. Make sure you have a browser installed (any modern browser works).
2. Save the `index.html` file in a folder.
3. Open the terminal (or Termux) and navigate to the folder.
4. Run a simple HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
5. Open your browser and go to `http://localhost:8000`.

> Note: If you open `index.html` directly in a browser without a server, some features like smooth scrolling still work, but hosting with a server is recommended.

## How to Deploy on GitHub Pages
1. Create a new repository on GitHub (e.g., `portfolio-website`).
2. Commit and push your `index.html` file to the repository.
3. Go to the repository `Settings` > `Pages`.
4. Under "Source," select the branch (usually `main`) and `/root` folder.
5. Save. GitHub Pages will provide a URL where your site is live.

Enjoy your live portfolio! 🌐
